E-Mail Versand

SMTP nutzt die eingetragenen Serverdaten. Outlook Classic wird unter Windows mit Microsoft 365 Desktop sowie Outlook 2016/2019/2021 unterstützt; das neue Outlook für Windows wird nicht unterstützt. Unter macOS ist eine Outlook-Version mit AppleScript-Unterstützung erforderlich.
Wichtig bei Versand über Outlook Classic: Outlook Classic muss vor dem Verbindungstest und während des gesamten Versands geöffnet, angemeldet und vollständig verbunden sein. Unter Windows werden Microsoft 365 Desktop (Classic) sowie Outlook 2016, 2019 und 2021 unterstützt. Das neue Outlook für Windows wird nicht unterstützt. Unter macOS ist eine Outlook-Version mit AppleScript-Unterstützung erforderlich.
